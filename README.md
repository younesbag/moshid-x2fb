# x2fb — نقل منشورات X إلى صفحة «مُشَيِّد Moshid» على فيسبوك

X هو المختبر، وفيسبوك هو المكبّر: لا يُنقل إلا ما أثبت نفسه على X.

## كيف يعمل (كل ساعة على GitHub Actions)

1. **يجلب** آخر منشوراتك الأصلية من X عبر twitterapi.io (بلا ردود ولا إعادات نشر).
2. **ينتظر ٢٤ ساعة** ثم يحكم على الأداء: التفاعل الموزون (الحفظ وإعادة النشر ×٢) مقابل آخر ٦٠ منشوراً لك. يُرشَّح **أعلى ٣٥٪** فقط، وما فات عليه أكثر من ٥ أيام لا يُنقل.
3. **يجمع الثريد كاملاً** (ردودك المتسلسلة على نفسك فقط).
4. **وكيل التحويل** يعيد صياغته لفيسبوك وفق `prompts/constitution.md`: يحذف الروابط والإشارات وآثار X، يدمج الثريد، يحافظ على صوتك وعلى البرومبتات حرفياً، ويتخطى العروض والأسعار والمنشورات العابرة والتشويق بلا محتوى.
5. **بوابة حتمية** (`x2fb/gate.py`) تمسك ما يفلت من النموذج: روابط، @، #، أسعار، Markdown، سهم معلّق.
6. **تلغرام**: معاينة بزرّين «✅ نشر / ❌ إلغاء».
7. **النشر**: منشور واحد يومياً بين ٥ و١٠ مساءً بتوقيت الرياض، بتوقيع «— يونس»، مع صور المنشور الأصلي إن كانت جزءاً من قيمته.

الفيديو لا يُنقل آلياً في هذه النسخة: يصلك تنبيه لتنقله يدوياً.

**الأوضاع (`MODE`):**
- `approval` (الافتراضي): لا شيء يُنشر بلا ضغطة «نشر».
- `veto`: يُنشر بعد ٣ ساعات من المعاينة ما لم تضغط «إلغاء».
- `auto`: بلا مراجعة.

## الأوامر

```bash
python -m x2fb check      # فحص كل الاتصالات، لا ينشر
python -m x2fb dry --n 5  # معاينة تحويل أفضل ٥ منشورات في out/preview.md، لا ينشر ولا يغيّر السجل
python -m x2fb run        # دورة كاملة
python -m unittest discover -s tests -v
```

## ما يحتاج إعداداً يدوياً منك (مرة واحدة)

### ١) توكن صفحة فيسبوك (`FB_PAGE_TOKEN`)

نفّذ الخطوات بنفسك في المتصفح. لا أداة آلية تلمس حساب ميتا.

1. افتح https://developers.facebook.com/apps، ثم «إنشاء تطبيق»، ثم حالة الاستخدام **«إدارة كل شيء على صفحتك»** (Manage everything on your Page). اسم التطبيق: `moshid-x2fb`.
2. التطبيق يبقى في **وضع التطوير**. لا حاجة لمراجعة ميتا، لأنك تنشر على صفحتك فقط.
3. افتح **Graph API Explorer**، واختر التطبيق، ثم «Get User Access Token» بالصلاحيات:
   `pages_show_list`، `pages_read_engagement`، `pages_manage_posts`.
4. حوّل التوكن إلى توكن طويل الأجل: افتح **Access Token Debugger** والصق التوكن، ثم «Extend Access Token».
5. في Explorer بالتوكن الطويل، نفّذ `GET me/accounts`. انسخ `access_token` الخاص بصفحة «مُشَيِّد Moshid». **توكن الصفحة المستخرج من توكن مستخدم طويل الأجل لا تنتهي صلاحيته.**
6. احفظه في GitHub بهذا الأمر (يطلب منك لصق القيمة، ولا تظهر على الشاشة):
   ```bash
   gh secret set FB_PAGE_TOKEN -R younesbag/moshid-x2fb
   ```

### ٢) بوت تلغرام (`TG_BOT_TOKEN` و`TG_CHAT_ID`)

لا تستعمل بوت younes-mind. عليه webhook، فلا يستطيع هذا النظام قراءة ضغطاتك منه.

1. في تلغرام افتح @BotFather، ثم `/newbot`، ثم اختر اسماً مثل `moshid_x2fb_bot`.
2. احفظ التوكن:
   ```bash
   gh secret set TG_BOT_TOKEN -R younesbag/moshid-x2fb
   ```
3. أرسل للبوت الجديد أي رسالة، ثم شغّل `python scripts/tg_chat_id.py` لقراءة معرّف محادثتك، واحفظه:
   ```bash
   gh secret set TG_CHAT_ID -R younesbag/moshid-x2fb
   ```

### ٣) نموذج التحويل

الافتراضي في GitHub هو **Gemini** بمفتاح younes-mind. البدائل:
- **Claude API:** يحتاج رصيداً في حساب Anthropic، فالمفتاح الموجود رصيده صفر الآن. بعد الشحن:
  ```bash
  gh variable set TRANSFORMER -b anthropic -R younesbag/moshid-x2fb
  ```
- **Claude باشتراكك:** يعمل عبر `claude -p` محلياً أو على VPS. لا يعمل على GitHub Actions إلا بتوكن `claude setup-token`.

## السجل

`state/ledger.json` يُحفظ في المستودع بعد كل دورة، ويسجل كل منشور وحالته وتاريخ كل انتقال.

قبل كل طلب نشر يُكتب طابع **ادّعاء** (`publishing`) ويُحفظ أولاً. إذا انقطعت الدورة بعد الطابع وقبل النشر، لا يُعاد النشر آلياً، فلا ينشر المنشور مرتين.
